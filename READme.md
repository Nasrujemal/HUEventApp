# HUEventApp

HUEventApp is a native Android application for Haramaya University that helps students, faculty, and staff discover and keep track of campus events.

## Features

- Browse and search campus events
- Filter events by category
- View event details
- Set reminders for upcoming events
- User registration and login
- Admin event management
- Active and expired event status
- Modern Material Design UI

## Tech Stack

- Android
- Java
- Material Design
- ConstraintLayout
- CoordinatorLayout

## Modules

- **Admin:** Create, update, and delete events
- **Users:** Browse events, search, and set reminders

## Future Improvements

- University calendar integration
- Event attendance tracking
- Social sharing
- Analytics
- iOS version

## NOTE

This project was developed as a university project for Haramaya University.
